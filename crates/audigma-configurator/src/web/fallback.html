Audigma configurator

The server is running and you are signed in, but this build of audigma has no web interface. The JSON API works.

To get the interface, build it once with bun install && bun run build in crates/audigma-configurator/web and rebuild audigma, or use a release binary. The terminal interface (audigma configure) needs none of this.

Try /api/meta, /api/draft and /api/guided/state.
